# Personal Finance Tracker

A backend API project for tracking personal expenses.

## Technologies

- ASP.NET Core
- C#
- PostgreSQL
- Npgsql
- REST API

## Current Features

- Get all expenses
- Get expense by id
- Create expense
- Update expense
- Delete expense
- Basic validation
- Error handling
- User registration
- User login
- Password hashing
- JWT authentication
- User-scoped expense access
